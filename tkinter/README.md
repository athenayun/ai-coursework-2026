# Tkinter Desktop Applications

Standalone Python desktop applications using Tkinter or CustomTkinter, covering data collection, exploration and document Q&A.

| Project | Description |
| --- | --- |
| [chickpt_taipei_job_scraper](chickpt_taipei_job_scraper/) | Taipei job listing scraper |
| [ctee-selenium-scraper](ctee-selenium-scraper/) | CTEE news collection using Selenium |
| [mops_tkinter](mops_tkinter/) | Desktop exploration of MOPS data |
| [remoteok_customtkinter](remoteok_customtkinter/) | Remote job listing exploration |
| [rag-tkinter-mac](rag-tkinter-mac/) | Standalone desktop RAG document Q&A application |

## Running locally

Use a Python environment with working Tk support. Install each application's own dependencies and follow its project README or entry-point instructions. Scrapers may require browser drivers or network access.

Desktop applications focused on messaging delivery are listed separately under [RAG, API & messaging integrations](../rag-api-messaging-integrations/).
