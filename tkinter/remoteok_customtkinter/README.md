# RemoteOK Job Scraper — CustomTkinter GUI

A Python desktop application developed as part of my Python coursework, exploring web scraping and GUI development using CustomTkinter.

## Overview

This project focuses on working with remote job-listing data from RemoteOK through a Python desktop interface.

The application serves as a practical exercise in combining data retrieval with GUI development.

## Tech Stack

- Python
- CustomTkinter
- Additional dependencies listed in `requirements.txt`

## Getting Started

**1. Install dependencies**

From this project's directory:

```bash
pip install -r requirements.txt
```

**2. Run the application**

```bash
python app.py
```
