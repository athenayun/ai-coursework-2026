# Chickpt Taipei Job Scraper

A Python desktop GUI application developed as part of my Python coursework, focusing on web scraping and job-listing data from Chickpt.

## Overview

This project explores integrating web scraping with a Tkinter-based graphical user interface, using Taipei job listings as the data source.

## Tech Stack

- Python
- Tkinter
- Web scraping libraries (see `requirements.txt`)

## Getting Started

**1. Install dependencies**

From this project's directory:

```bash
pip install -r requirements.txt
```

**2. Run the application**

```bash
python app.py
```
